# NFL App

[NFL App](https://nflapp.streamlit.app/) is an interactive Streamlit website for exploring NFL games and team trends.

It lets you:
- Browse games by filtering all games, primetime games, playoff games, team games, divisional games, and team matchups
- Open individual games to view a drive-based field visualization
- See game stats like yards, EPA, success rates, red zone efficiency, turnovers, sacks allowed, fourth down rate, and explosive plays
- View win probability charts for selected games
- Explore offensive, defensive, and overall team rankings across multiple seasons

The app is built to make it easier to compare teams, study specific games, and visually explore NFL data.
